Command Catalog

Clean, intuitive commands for both admins and members

bash: aniyamusic-cli v2.0
Command Description Scope
/play <query/link> Streams audio track into the voice chat from YouTube, Spotify, or Apple All Users
/vplay <query/link> Streams HD video with synced stereo audio directly to video chat All Users
/pause | /resume Temporarily halts or resumes active voice chat streaming Admins
/skip Instantly skips the current track to the next queued item Admins
/seek <seconds> Fast-forwards or rewinds the current track to specified timestamp Admins
/speed [0.5 - 2.0] Dynamically adjusts playback speed in real-time Admins
/queue Displays full queued playlist with track durations and requester tag All Users
/cplay <channel_id> Links and streams directly to a connected announcement channel Admins
